# SoundBlocker (音ブロッカー) 🎧🚫

複数のアプリで同時に音や音楽が再生されている場合に、ワンタップで任意のアプリの音声を個別かつ完全にブロック（停止）できるAndroidアプリです。

---

## ⚡ 「通話と音声」ではなく「ゲームとYouTube」の重なり問題に対応！

「通話（STREAM_VOICE_CALL）」と「メディア音声（STREAM_MUSIC）」はAndroidの標準設定で別々のスライダーがあるため、通話中にゲーム音を下げることは可能です。

しかし、**「ゲームの音声」と「YouTube/音楽の音声」はどちらも同じ【メディア音声】に属しているため、端末の音量ボタンを操作すると両方一緒に音量が変わってしまい、どうしても音が重なってしまいます。**

**SoundBlocker** はこの問題を解決するために、以下のハイブリッド方式でどちらか一方の音を完全ブロックします：

1. **🎬 YouTube側を消したい時 (ゲーム音のみ残す)**:
   - `MediaSessionManager` 連携により、裏で流れているYouTube・音楽の再生をワンタップでバックグラウンド停止。
2. **🎮 ゲーム側を消したい時 (YouTube音のみ残す)**:
   - 曲情報を持たないゲームアプリに対しても、Androidの深層音声権限（`PLAY_AUDIO` / AppOps）やオーディオフォーカス制御により、ゲーム音を完全ブロック。
3. ** floating フローティング・オーバーレイ**:
   - ゲーム画面を開いたままでも、画面端の小さなバブルから「ゲーム音ブロック」「YouTube音ブロック」を瞬時に切り替え可能！

## ✨ 主な機能

### 1. ゲーム ✕ YouTube 重なりワンタップ解決
- **「YouTubeを消す」** / **「ゲームを消す」** / **「両方鳴らす」** を1タップで切り替え。
- アプリ画面および画面上のフローティングバブルの両方に対応。

### 2. 再生中メディアのリアルタイム検知 & 個別ブロック
- YouTube、Spotify、Chromeブラウザ、各種プレーヤーをリアルタイム検知。

### 3. ゲーム・全アプリの個別消音 (AppOps連携)
- 端末にインストールされているゲームアプリを自動判別して一覧表示。
- アプリごとの消音スイッチ ＆ ADB / Shizuku コマンドのワンタップコピー。

### 4. 快適で安心なアプリ内更新 (In-App Updater)
- **最低3秒以上の安心読み込み保証**: 通信後も安心感ある読み込み演出を挟みます。
- **次回の更新内容の詳細表示**: リリースノートをダイアログ内に見やすく整形表示。
- **ダウンロードアニメーション & 正確な進行バー**:
  - パルスアニメーション表示
  - `SmoothProgressBar`（滑らかな進行バー）
  - 小数点第1位までの正確なパーセンテージ（例: `45.2%`）
  - ダウンロード済みサイズ / 総サイズ / 転送速度（例: `3.5 MB/s • 1.2 MB / 4.1 MB`）
- **ワンタップインストール**: ダウンロード完了後、Android公式インストーラーが自動起動。
