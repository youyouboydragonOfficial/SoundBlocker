# SoundBlocker (音ブロッカー) 🎧🚫

複数のアプリで同時に音や音楽が再生されて音が重なった場合に、**消したい方のアプリの音声を自分で自由に選択して完全ブロック（停止）**できるAndroidアプリです。

---

## ⚡ 複数のアプリで音が重なる問題を自由に選択解決！

Androidでは「通話」と「メディア」は別々の音量スライダーがありますが、ゲーム、動画アプリ、音楽アプリ、SNS（X/Twitter、TikTok、Instagram等）、ブラウザなどはすべて同一の【メディア音声】として出力されるため、標準の音量ボタンでは片方だけを消すことができません。

**SoundBlocker** は特定のアプリに固定せず、**現在音を出しているすべてのアプリをリアルタイムで動的に検出し、ユーザーが「消したいアプリ」をその場で自由に選んでブロック**できます！

---

## ✨ 主な機能

### 1. 動的音声重複セレクター (リアルタイム選択)
- 複数のアプリで音が同時に鳴っている時、そのアプリ名とアイコンを検知。
- `[ 🚫「〇〇」の音を消す ]` のように、現在鳴っているアプリに応じた選択ボタンが自動生成され、消したい方をタップするだけで即座にブロック！
- 「すべての音を鳴らす（ブロック解除）」もワンタップ。

### 2. 画面上のフローティング・ブロックボタン (Overlay Widget)
- ゲームや別アプリを操作している最中でも、画面端の小さなバブルをタップして、今鳴っているアプリ一覧からワンタップで消したいアプリを選択可能。

### 3. 全アプリ一覧からの自由選択 (AppOps / PLAY_AUDIO)
- 端末内のすべてのゲーム、SNS、動画、ブラウザアプリを一覧表示。
- スイッチで消音対象を事前に自由に選んで登録できます。

### 4. 快適で安心なアプリ内更新 (In-App Updater)
- **最低3秒以上の安心読み込み保証**: サーバー照合の安心演出を挟みます。
- **次回の更新内容の詳細表示**: リリースノートをダイアログ内に見やすく整形表示。
- **ダウンロードアニメーション & 正確な進行バー**:
  - パルスアニメーション表示
  - `SmoothProgressBar`（滑らかな進行バー）
  - 小数点第1位までの正確なパーセンテージ（例: `45.2%`）
  - ダウンロード済みサイズ / 総サイズ / 転送速度
- **ワンタップインストール**: ダウンロード完了後、Android公式インストーラーが自動起動。
