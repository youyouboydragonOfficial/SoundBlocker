# SoundBlocker (音ブロッカー) 🎧🚫

複数のアプリで同時に音や音楽が再生されている場合に、ワンタップで任意のアプリの音声を個別かつ完全にブロック（停止）できるAndroidアプリです。

---

## 💡 開発の背景：なぜAndroidには個別音量設定がないのか？

Android OSの標準仕様（AudioFlinger / AudioManager）では、音量は「メディア音声」「通話音声」「着信音」「アラーム」などの**大枠ストリーム単位**でしか管理されていません。
Windowsや一部の特殊なOEM拡張（Samsung GalaxyのSoundAssistantなど）を除き、一般のAndroidアプリはサンドボックスセキュリティの制約により他アプリの音声ミキサーに直接介入することが制限されています。

**SoundBlocker** は、Androidの `MediaSessionManager`（メディアセッション制御）および `AudioFocus`（オーディオフォーカス規約）を高度に連携させることで、**一般アプリでありながらバックグラウンドの特定アプリの音声をピンポイントで停止・ブロック**することを実現しました。

---

## ✨ 主な機能

### 1. 再生中アプリのリアルタイム検出 & 個別ブロック
- YouTube、Spotify、ブラウザ（Chrome）、各種音楽・動画アプリの再生状況をリアルタイムで検知。
- アプリ一覧から、邪魔なアプリの「**音をブロック**」ボタンを押すだけで即座に音声を停止！
- 「ブロック解除」でいつでも再開可能。

### 2. 画面上のフローティング・ブロックボタン (Overlay Widget)
- 画面端に常駐する移動可能なサウンドブロックバブル。
- ゲームプレイ中や別アプリを開いている最中でも、画面を切り替えることなくワンタップで裏の音楽や動画を即ブロックできます。

### 3. バックグラウンド音声の一斉消音 (Exclusive Focus)
- オーディオフォーカスを強制的に独占し、バックグラウンドで鳴っている他アプリの音声を一斉にミュート/一時停止させます。

### 4. 快適で安心なアプリ内更新 (In-App Updater)
ユーザーの安心感と使いやすさを追求した高度なアップデートシステムを内蔵：
- **最低3秒間の安心読み込み**: 早すぎるチェックによる不信感を防ぐため、3秒以上の通信・照合時間を保証。
- **次回の更新内容の詳細表示**: リリースノート（Changelog）をダイアログ内に見やすく整形表示。
- **ダウンロードアニメーション & 正確なインストール進行バー**:
  - パルスアニメーション表示
  - `SmoothProgressBar` による滑らかなアニメーション
  - 小数点第1位までの正確なパーセンテージ（例: `45.2%`）
  - バイト数およびリアルタイム転送速度（例: `3.2 MB/s • 1.8 MB / 4.0 MB`）
- **ワンタップインストール**: ダウンロード完了後、Android公式インストーラーが自動起動。

---

## 🛠️ 動作要件
- Android 8.0 (API 26) 以上
- 必要な権限:
  - **通知アクセス権限**: 再生中のメディアセッションを検知・制御するために必要です。
  - **他のアプリの上に重ねて表示**: フローティングボタンを使用する場合に必要です。
